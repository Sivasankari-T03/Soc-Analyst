How to Connect Authorized Windows Devices

Run the lightweight endpoint collector on any Windows machine connected to the same authorized private lab network: 

# On the target Windows device (Run PowerShell as Administrator):
cd collectors
.\windows-collector.ps1 -ServerUrl http://YOUR_LAPTOP_IP:3000/api/ingest -ApiKey labtrace-secret-key

🔒 Privacy Boundary: Collects exclusively logon Event IDs 4624 (Success) and 4625 (Failure) metadata. Passwords, keystrokes, personal messages, and browser contents are never monitored.
