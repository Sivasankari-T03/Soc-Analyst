Collector Quick Start

1. Windows PC or Domain Controller:

# Run PowerShell as Administrator:
cd collectors
.\windows-collector.ps1 -ServerUrl http://localhost:3000/api/ingest

2. Linux VM or Public Cloud Honeypot:

# Expose port 22 on cloud VM, then run:
export SERVER_URL=http://YOUR_SERVER_IP:3000/api/ingest
sudo bash collectors/linux-collector.sh

Rules explained

🔁
R1Failure burst then success
When a successful login is preceded by N or more failed attempts within the last W minutes on the same account and computer.
🌙
R2After-hours success
A successful login outside configured lab open/close times or on a non-working day.
🐢
R3Slow failures then success
N3 or more failures within 24 hours before a success, catching slow guessing.
🚫
R4Failures, no success yet
Burst or multiple failures with no access gained yet.
🔀
R5Failures on another computer
Failures on one PC then success on a different PC.
💧
R6Password spraying
Multiple different user accounts failing on the same workstation within W minutes.
LabTrace SOC prioritizes review. It never accuses anyone and never blocks an account without supervisor sign-off.

Detection parameters

No working day selected — every success will be treated as outside lab hours.
